# Tavo Images · Картинки

Генерация и доработка изображений прямо в чате **Tavo**.
Адаптация для Tavo на основе [notsosillynotsoimages](https://github.com/aceeenvw/notsosillynotsoimages) от **aceeenvw**; исходный проект — [SillyImages](https://github.com/0xl0cal/sillyimages) от **0xl0cal**.
Разработка версии для Tavo: **NotFound_404 / Not_Found** ([NotFound404dev](https://github.com/NotFound404dev)).

**Версия: 1.38.0.** [Скачать готовый плагин](https://github.com/NotFound404dev/tavo-images/releases/latest) · [Изменения](CHANGELOG.md) · [Все авторы и благодарности](CREDITS.md) · [Лицензия](LICENSE)

## Возможности

- Иллюстрации к постам персонажей: автоматически или по кнопке.
- Отдельная модель для написания промптов, библиотека стилей и свои инструкции.
- Референсы персонажа и персоны, фотографии и текстовые описания внешности.
- Подключения OpenAI-совместимых API, Gemini, Naistera, NovelAI и Tensor Art.
- Галерея, избранное, перегенерация, редактирование промпта и доработка изображений.
- Студия генерации, сохранённые настройки, доски одежды и локаций.
- Взаимодействие с плагином «Память»: создание и доработка карт мира.
- Русский и английский интерфейс.

Доступные режимы генерации и референсов зависят от выбранного провайдера и модели.

## Установка

1. Откройте [Releases](https://github.com/NotFound404dev/tavo-images/releases) и скачайте `tavo-images-1.38.0.tpg` из раздела **Assets**.
2. Импортируйте `.tpg` в разделе плагинов Tavo и включите плагин для нужного чата.
3. В чате откройте меню **«+» → «Картинки»**. Плавающую кнопку можно отдельно включить в настройках плагина.
4. В панели настройте провайдера генерации: адрес API, свою модель и свой ключ. Для промптов выберите модель чата или отдельное подключение.
5. Настройте стиль, референсы и режим генерации.

Для установки нужен Tavo с поддержкой плагинов спецификации 2. Это пакет для Tavo; установка через менеджер расширений SillyTavern не поддерживается.
Ключи API вводятся пользователем в Tavo. Учётные данные и оплаченные услуги провайдеров в поставку не входят.
Для карт мира нужен совместимый плагин «Память», который устанавливается отдельно.

## Сборка из исходников

Требуется **Python 3.10+**. Базовая сборка использует только стандартную библиотеку.

```bash
python3 build.py
```

Результат: `dist/tavo-images-1.38.0.tpg` и `dist/SHA256SUMS`.
Архив содержит текущий плагин, `LICENSE`, `NOTICE` и `CREDITS.md`. Исходники соответствующей версии доступны по тегу релиза.

Для проверки JavaScript и тестов карт мира нужен **Node.js 18+**:

```bash
python3 verify.py
```

Проверка не обращается к API провайдеров и не тратит кредиты.

## Где править код

| Файл или папка | Назначение |
| --- | --- |
| `plugin_p1/entry.js` | Исходное ядро, из которого сборщик извлекает используемые функции |
| `tail_p95.js` | Текущий управляющий слой Tavo, провайдеры, студия и интеграции |
| `build_p95.py` | Сборка движка и преобразования исходного ядра |
| `plugin_p2/entry.js` | Собранный движок; пересоздаётся при сборке |
| `plugin_p2/ui/` | Исходники панели настроек и фрагмента изображения |
| `plugin_p2/manifest.json`, `plugin_p2/locales/` | Манифест и локализация плагина |
| `i18n/ru_en.json`, `i18n_tool.py` | Словарь и инструмент локализации интерфейса |
| `previews_src/`, `make_previews.py` | Исходники превью стилей и сборка листа превью |
| `tests/` | Регрессионные проверки карт мира с подставными провайдерами |

После правки интерфейсных переводов выполните `python3 i18n_tool.py emit`, затем обычную сборку.
Для пересборки превью дополнительно установите Pillow и выполните `python3 make_previews.py`.
Для обычной сборки готовые превью уже включены.

## Публикация следующей версии

Обновите версию в манифесте, тексты `plugin.releaseNotes` обеих локалей и `release-notes.md`, пересоберите проект и выполните проверки.
Workflow **Build and release** собирает и проверяет пакет при изменении версии в `main`; его также можно запустить вручную во вкладке Actions.
Релиз создаётся только если тега этой версии ещё нет. Уже опубликованные файлы не перезаписываются.
