# Картинки для Tavo

Генерация и доработка изображений в чате Tavo: стили, референсы, галерея, студия, Доски и карты мира через плагин «Память».

**Версия 1.38.0** · [Скачать плагин](https://github.com/NotFound404dev/tavo-images/releases/latest) · [Авторы и благодарности](CREDITS.md)

## Установка

1. Скачайте `.tpg` из раздела **Assets** в релизе.
2. Импортируйте его в плагины Tavo и включите для чата.
3. Откройте **«+» → «Картинки»** и настройте свой API, модель, стиль и референсы.

Нужен Tavo с поддержкой плагинов спецификации 2. Доступные режимы зависят от провайдера. Для карт мира нужен совместимый плагин «Память», устанавливаемый отдельно.

## Исходники и сборка

Все актуальные исходники и ресурсы находятся в **`src/`**. Правки вносятся прямо туда: `entry.js` — движок, `ui/` — интерфейс, `locales/` — описания и переводы. Интерфейсные переводы также находятся в словарях `EN_DICT` внутри HTML.

Упаковка без сторонних зависимостей, Python 3.10+:

```bash
python3 build.py
```

Готовый пакет и его SHA-256 появятся в `dist/`. Упаковщик не преобразует код.
