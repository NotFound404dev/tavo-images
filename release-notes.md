Версия **1.38.0** плагина «Картинки» для **Tavo**.

- Создание карт мира из «Памяти»: подписи, описания мест и три стиля.
- Доработка выбранной карты и добавление отметок с сохранением исходной версии.
- Возврат результата в библиотеку и исходный чат.
- Первая публикация адаптации в GitHub: исходники, переносимая сборка, AGPL-3.0-or-later и сведения об авторах.

Для установки скачайте **tavo-images-1.38.0.tpg** из Assets и импортируйте его в Tavo.
`SHA256SUMS` содержит контрольную сумму пакета.
Исходники и сборщик доступны в этом репозитории по тегу **v1.38.0**.

Основано на [notsosillynotsoimages](https://github.com/aceeenvw/notsosillynotsoimages) от **aceeenvw** и [SillyImages](https://github.com/0xl0cal/sillyimages) от **0xl0cal**.
Адаптация и развитие для Tavo — **NotFound_404 / Not_Found**.

Дополнительные источники, идейные ориентиры, авторы встроенных стилей и разрешение на промпт комикса перечислены в [CREDITS.md](https://github.com/NotFound404dev/tavo-images/blob/v1.38.0/CREDITS.md). Полный список включён в установочный пакет.

Проверены воспроизводимость сборки, синтаксис JavaScript и 14 сценариев карт мира с подставными провайдерами. Живая генерация через API и установка этой сборки на устройства при подготовке публикации не проверялись.
